# CN Product Extractor — 用户使用指南

本扩展用于在京东/天猫/淘宝网页上导出商品数据，保存为 `.jsonl` 文件（**详情 JSONL**）：每行一条完整商品（标题、价格、规格、变体、长描述等），典型文件名 `cn-details-2026-09-01-1234567890.jsonl`。

弹窗底部会显示：`当前缓存：详情 N 条（最多保留 10000 条，超出自动删除最旧）`。

---

## 一、安装扩展

1. 获取本项目的文件夹（需包含 `manifest.json`）。
2. 打开浏览器扩展页面：
   - **Chrome**：`chrome://extensions`
   - **Edge**：`edge://extensions`
3. 打开 **「开发者模式」** → **「加载已解压的扩展程序」** → 选中项目文件夹。
4. 将扩展图标固定到工具栏。

> 无需安装 Node.js，安装后直接在网页上使用即可。

---

## 二、能用在哪些页面？

| 页面 | 能做什么 |
|------|----------|
| 京东商品详情 `item.jd.com/xxx.html` | 提取完整商品信息 → **详情缓存** |
| 天猫商品详情 `detail.tmall.com/item.htm?id=…` | 提取完整商品信息（含 SKU 变体、图文详情）→ **详情缓存** |
| 淘宝搜索列表 `s.taobao.com/search…` | 提取列表级商品数据 → **详情缓存** |

---

## 三、商品详情页（京东 / 天猫）

1. 打开商品页，等待加载完成。
2. 点击扩展图标 **「提取并写入缓存」**，或页面右下角浮动按钮。
3. **京东**：需先手动向下滚动，等图文详情加载后再点提取；**天猫**：直接点提取即可。
4. 提取完成后用 **「统一下载全部 JSONL」**（弹窗或页面浮动按钮）导出缓存中的全部商品。

| 按钮 | 作用 |
|------|------|
| **提取并写入缓存** | 提取商品写入详情缓存（不自动下载） |
| **复制 JSON** | 复制最近一次提取结果 |
| **统一下载全部 JSONL** | 把缓存中的全部记录导出为单个 JSONL 文件（`cn-details-*.jsonl`） |
| **清空详情缓存** | 删除全部详情记录（不可恢复） |

> 导出后的 JSONL 文件可上传到 everymarket 后台 **CN Product Imports** 页面（`/dashboard/cn_product_imports/new`）导入商品；扩展内不做定价与上传。
> 商品页浮动按钮提供「提取并写入缓存」和「下载全部 JSONL」两个按钮；缓存上限 10000 条，适合批量逐个提取后一次导出。

---

## 四、淘宝搜索列表页

- **提取本页列表**（页面右下角浮动按钮）：提取当前页所有商品 → 写入详情缓存。
- **翻页提取列表**：自动翻页后提取多页列表数据 → 写入详情缓存。
- 扩展弹窗的 **「提取搜索列表」** 为提取当前页列表并写入缓存。
- 提取后可用 **「下载全部 JSONL」**（浮动按钮）统一导出缓存。

---

## 五、详情缓存规则

- 最多保留 **10000 条**；超过后自动删除最旧的记录。
- 同一商品重复提取会去重后更新。
- 「统一下载全部 JSONL」导出的是缓存内的全部记录（单个 JSONL 文件）。

---

## 六、常见问题

**提取超时**  
→ 确认商品页在前台且已加载完成；京东页需先滚动加载图文详情。

**京东搜索/列表页打开扩展没有按钮**  
→ 自动抓取（翻页缓存链接/批量详情/深度抓取）已移除；请打开商品详情页或淘宝搜索列表页。

**重装扩展后数据没了**  
→ 请及时用「统一下载全部 JSONL」备份。

---

## 七、快速对照

| 目标 | 操作 |
|------|------|
| 导 1 个商品完整信息 | 商品页 → 提取并写入缓存 → 统一下载全部 JSONL |
| 导一批商品（手动逐个） | 打开每个商品页 → 逐个提取并写入缓存 → 最后统一下载 |
| 淘宝搜索页导列表 | 搜索页 → 提取本页/翻页提取列表 → 统一下载全部 JSONL |
